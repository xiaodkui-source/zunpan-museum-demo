# 曾侯乙尊盘模型放置说明

正式模型文件应放置为 `public/models/zunpan.glb`，应用运行时通过
`/models/zunpan.glb` 访问。

请勿提交空文件，也不要把其他格式文件改名伪装为 GLB。替换模型前，应先在可靠的
glTF 查看器中确认文件能够打开、结构完整且材质显示正常。当前正式模型缺失时，应用
会使用程序化构建的“上尊 + 下盘”数字结构示意，不会把占位内容冒充真实扫描模型。

首屏使用的 GLB 建议在压缩后控制于 8–15 MB 内，并按实际内容合理合并网格与材质、
清理无用节点。若制作与发布工作流支持，可评估 Draco、Meshopt 与 KTX2 压缩；上线前
还必须复核模型原点、比例、朝向以及与各热点坐标的对应关系。
